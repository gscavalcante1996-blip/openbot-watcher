# openbot-watcher
A PowerShell watcher that monitors Google Drive task folders every 5 minutes and fires the OpenBot webhook when a new task file appears. It powers the automated video production pipeline for our YouTube channels (Bible storytelling, GTA 6 news, history).

E lembra: mesmo que o botão libere, a aprovação continua improvável por causa da conta recente. Mas o repositório é de verdade e fica pra você de qualquer jeito.
